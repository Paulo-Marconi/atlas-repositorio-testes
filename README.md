# Repositório de testes do ATLAS

Materiais da avaliação experimental de detecção de problemas estruturais: dez exemplos TypeScript, cinco cenários e 30 problemas de referência.

A [documentação do experimento](atlas-repositorio-testes/README.md) reúne protocolo, fontes, referências e planilha de coleta.

Com Node.js 22.13 ou superior e pnpm 11.25.0, execute na raiz:

```sh
pnpm install --frozen-lockfile
pnpm verify
```
